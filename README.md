# Սովորել 3D ծրագրավորում

## Նպատակները

1. Սովորել 3D պատկերների հետ աշխատանքը ամենապարզ մակարդակից սկսած. մաթեմատիկա, պրիմիտիվներ նկարել, գունավորել և այլն։
2. Սովորել ու կիրառել ժամանակակից C++ լեզուն (նվազագույնը՝ 23-րդ ստանդարտը)։

## Կոդը

Նախընտրելի build միջավայրը `clang++` + `Ninja`-ն է, որովհետև նախագիծը օգտագործում է C++23 modules և `import std`.

```bash
cmake --preset clang-ninja
cmake --build --preset clang-ninja
ctest --preset clang-ninja
```
